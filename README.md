# shenhaojiaoben

《都市神豪之我爱装逼·完整版》云端扩展脚本仓库。

## 目录结构

- `phone/index.js`：小手机/平板（HUD ＋ 微信 ＋ 直播间 ＋ 星探 ＋ 媒体桥 ＋ 名器与特殊体质引擎）

## 使用方式（手动改版本号更新）

在 SillyTavern 酒馆助手（Tavern Helper）的 `小手机/平板` 脚本中写入：

```js
import 'https://gcore.jsdelivr.net/gh/yizichen123/shenhaojiaoben@v7.3/phone/index.js';
```

发公告出新版本时，只需修改 `@` 后面的版本号（例如将 `@v7.3` 改为新公告里的版本号）并点击确认即可。

## 版本历史

- `v7.2.2` / `v7.2.1`：移除名器年龄与徐朵朵限制、保留 5 项私密字段校验。
- `v7.2`（对应角色卡《都市神豪之我爱装逼完整版7.2》初始云端版）
